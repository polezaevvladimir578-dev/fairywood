Условия использования игры «Карманное королевство»

«Карманное королевство» — семейная шахматная игра студии FairyWood для Android с возрастной маркировкой 6+. Издатель — индивидуальный предприниматель Полежаев Владимир Михайлович, Россия. По вопросам игры, доступа к урокам и работы приложения можно написать на 225705@mail.ru.

Игру можно бесплатно установить из RuStore. Первые девять уроков, обычные партии против компьютера и игра вдвоём на одном устройстве доступны бесплатно, без ограничения по времени.

В разделе для родителей взрослый может открыть уроки 10–117 одной покупкой «Полная Академия» за 199 ₽. Оплату проводит RuStore. Перед подтверждением взрослый видит цену в платёжном окне. Повторных списаний по подписке нет.

После переустановки откройте RuStore с аккаунтом, через который была сделана покупка, и выберите восстановление покупки в разделе для родителей. Для покупки и её восстановления нужен интернет. По вопросам доступа к оплаченному курсу напишите издателю. По вопросам платежа или возврата также можно обратиться в поддержку RuStore. Права покупателя определяются применимым законодательством.

Партии и учебный прогресс хранятся на устройстве. Перед переносом на другое устройство сохраните копию прогресса через настройки игры. При восстановлении покупки открываются оплаченные уроки. Для переноса сыгранных партий и результатов занятий нужна сохранённая копия прогресса.
